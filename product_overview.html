ครบทุกการใช้งานของครัว

ออกแบบมาเพื่อการใช้งานจริงในครัวร้านอาหาร ลดขั้นตอน เพิ่มความเร็ว

🔄
Real-time Order Queue
ดึงคิวอาหารจาก Pixel POS อัตโนมัติทุก 15 วินาที ไม่ต้อง refresh มือ แสดงสถานะรอทำ / กำลังทำ แบบ live
✅
Checkout & Undo
กด Checkout เพื่อยืนยันรายการเสร็จ กด Undo เพื่อย้อนกลับทันทีหากกดผิด — ป้องกันข้อมูลหาย
🔢
Checkout 3 โหมด (เมื่อจำนวน > 1)
โหมด 1: ทีละ 1 รายการ — เหมาะจานที่ทำทีละอัน
โหมด 2: จบทั้งหมดในครั้งเดียว — เหมาะเครื่องดื่ม
โหมด 3: เลือกจำนวนเอง — เชฟกดเลือก 1–N จาก popup
🔒
2-Step Checkout
เปิดโหมด 2 ขั้นตอน — กดครั้งแรก "ยืนยันไปครัว" ก่อน ป้องกันกดพลาด เหมาะครัวที่ต้องการความแม่นยำสูง
📷
Barcode / QR Scan
รองรับสแกนเนอร์ USB (keyboard mode) และกล้องมือถือ / tablet สแกนต่อเนื่องอัตโนมัติทุก 800ms รองรับ numeric และ QR code
🔔
เสียงแจ้งเตือน order ใหม่
เล่นเสียงเมื่อมี order ใหม่เข้า รองรับอัปโหลดไฟล์เสียงเอง (.wav/.mp3) หรือทดสอบเสียงได้จาก Settings
⏱️
Timer & Color Alert
นับเวลาทุกรายการ เปลี่ยนสีการ์ดเมื่อใกล้เกินเวลา (เหลือง) และเกินเวลา (แดง) ตั้งค่าเกณฑ์นาทีได้เองใน Settings
🗂️
SET Menu รองรับเมนูชุด
แสดงชื่อชุด (parent) และรายการย่อย (child) แยกชัดเจน label สีเขียวคั่น ไม่สับสนกับสถานะอื่น
📍
Zone Filter
แต่ละจอ KDS เลือกดูเฉพาะโซนที่รับผิดชอบ (ครัวหลัก / บาร์ / สลัด) ล็อคโซนไม่ให้เปลี่ยนโดยไม่ตั้งใจ จำโซนข้ามรอบ refresh
🍽️
SaleMode Filter
แต่ละสถานี KDS กรอง SaleMode ได้อิสระ เช่น จอครัวดูเฉพาะ Dine-in, จอบาร์ดูเฉพาะ Delivery
❌
ควบคุมสินค้าหมด
กด "สินค้าหมด" จากหน้าจอ KDS ได้เลย ค้นหาชื่อสินค้า toggle สถานะ หมด/มีสินค้า — ส่งข้อมูลกลับ Pixel POS ทันที
🔀
แสดงโต๊ะที่ถูกย้าย
card แสดง badge "ย้ายโต๊ะ" (สีน้ำเงิน) เมื่อ order มีการย้ายโต๊ะ เชฟรู้ทันทีว่าควรส่งไปโต๊ะไหน
👨‍🍳
Staff Login บน Topbar
กรอกรหัสพนักงานได้จากหน้าหลักโดยตรง บังคับ login ก่อน checkout ทุกช่องทาง บันทึก activity log ทุกการกระทำ
🔐
Screen Lock
ล็อคหน้าจอเมื่อไม่ใช้งาน ป้องกันคนที่ไม่เกี่ยวข้องกดโดยไม่ตั้งใจ รองรับหลายเครื่องพร้อมกัน
📐
ปรับขนาด Card & Font
เลือกขนาดการ์ด S / M / L / XL และ Font Scale 85–130% ผ่าน Settings → หน้าตา รองรับจอทุกขนาดตั้งแต่ tablet ถึงจอ TV
📡
DB Offline Banner
แสดงแถบแดงเมื่อขาดการเชื่อมต่อ 3 รอบติดกัน พร้อมปุ่มลองใหม่ หายเองเมื่อกลับมา online — ไม่ต้อง refresh มือ
🏪
Multi-KDS หลายจุด
ติดตั้งหลายสถานีบน IIS เดียวกัน ผ่าน subfolder (KDS1, KDS2, ...) แต่ละจุดมี settings แยกกัน ไม่ปนกัน
📋
Activity Log
บันทึกทุกการ checkout, undo, confirm พร้อมรหัสพนักงาน วันเวลา และเมนูที่จัดการ — ใช้ตรวจสอบย้อนหลังได้
การตั้งค่า
ปรับได้ทุกอย่างจากหน้าจอ

ไม่ต้องแก้ไฟล์ config ด้วยมือ — ตั้งค่าทุกอย่างผ่าน Settings modal บนหน้าจอได้เลย

พร้อมติดตั้งกับ Pixel POS

ไม่ต้องซื้อ hardware พิเศษ รองรับจอ tablet มือสอง หรือ PC เก่า

💡
ทำงานผ่าน Browser ได้เลย — ไม่ต้องติดตั้ง app เพิ่ม เปิดบน Chrome / Edge บน Windows, Android tablet, iPad ได้ทันที ต่อ Wi-Fi เข้า server เดียวกับ Pixel POS
รายการ รายละเอียด
Platform PHP + MySQL รองรับ Windows IIS และ Apache ✓ รองรับ
Browser Chrome, Edge (รองรับ BarcodeDetector API) — Firefox ใช้ jsQR fallback ✓ รองรับ
อุปกรณ์ PC, Windows tablet, Android tablet, iPad — จอขนาดใดก็ได้ ✓ รองรับ
Multi-KDS ติดตั้งหลายสถานีผ่าน subfolder บน IIS server เดียว ✓ รองรับ
Barcode Scanner USB / Bluetooth scanner (keyboard mode) และกล้องสแกน QR ✓ รองรับ
Offline Detection แสดง banner แจ้งเตือนเมื่อ DB ขาดการเชื่อมต่อ ลองใหม่อัตโนมัติ ✓ รองรับ
PWA / Fullscreen รองรับ manifest.php และปุ่มเต็มจอ — ดูสะอาดเหมือน native app ✓ รองรับ
Activity Log บันทึก log ทุก checkout / undo / confirm พร้อมพนักงานและเวลา ✓ รองรับ
ฐานข้อมูล MySQL 5.1+ เชื่อมตรงกับ DB ของ Pixel POS ✓ รองรับ
Polling interval ทุก ~15 วินาที (configurable) — zone cache refresh ทุก ~60 วินาที ✓ รองรับ
