Features
ฟีเจอร์หลัก
  • 🔄
    Refresh อัตโนมัติดึงออเดอร์ใหม่ทุก 15 วินาที — ถ้า DB ออฟไลน์จะแสดง banner แจ้งเตือน
  • 🔊
    เสียงแจ้งเตือนเปิด/ปิดได้ต่อสถานี รองรับอัปโหลดเสียงเอง
  • 🏪
    กรองโซน / SaleModeแต่ละสถานีเลือกแสดงเฉพาะโซนหรือประเภทการขายที่รับผิดชอบ
  • 🖥️
    Multi-KDSติดตั้งหลายจุดในโฟลเดอร์ย่อย แต่ละจุดมี settings แยกกัน
  • 🔒
    Screen Lockล็อคหน้าจออัตโนมัติ รองรับสูงสุด 3 หน้าจอต่อสถานี

Constraints
สิ่งที่ต้องระวัง
  • 🚫
    ไม่แก้ Schema DB ของ POSห้าม ALTER TABLE / CREATE TABLE — DB เป็นของ vendor POS
  • 🔑
    settings.local.php ต้องตั้งต่อเครื่องมี DB credentials อยู่ — ไม่ sync ผ่าน Git
  • 🌙
    ร้านรันข้ามเที่ยงคืนต้องปิด "แสดงเฉพาะออเดอร์วันนี้" ในสถานีนั้น มิฉะนั้น order จะหายหลังเที่ยงคืน
  • 🌐
    รองรับ IIS & Apacheถ้าใช้ IIS ต้องมี web.config — HTTP error ต้องส่งผ่าน JSON เท่านั้น (IIS intercept 4xx/5xx)
